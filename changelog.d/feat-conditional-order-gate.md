The new PreToolUse gate is the mirror of `promise-gate` on the operator's side: when the operator's last message (no harness notification, no hook echo — `turn-kind.cjs`) carries a condition word — then / after your answer / once … merged / wait for / clear it with X / X decides — the first expensive or externally effective call of the turn is held: a `Workflow` always, an `Agent` from the third call in the turn, a shell command that leaves the machine or starts a model (`claude -p`, `git push`, `gh pr create|comment|review|merge`, `gh issue create|comment`, `gh api … -X`). It passes once the turn holds one line `CONDITION-MET: <condition> — <evidence>` or `CONDITION-NONE: <why not>`; it does not judge the condition, it forces the check that was skipped, and a false positive costs one line. Reads, edits, commits and single agents stay free. Fail-open without a transcript.
