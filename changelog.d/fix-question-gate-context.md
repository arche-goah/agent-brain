- **`question-gate.cjs`: a recorded question keeps the text before it, and the session-start list prints it as `about:`.** (test: T1) Measured 2026-10-12 on the Windows instance: "Do you want it, and when?" (the coherence scan) stood at three session starts as a bare sentence. The operator had decided it the day it was asked ("yes, in its own session", in the brain's ledger), but the agent of that session filed it `unanswered`, and no later session could tell which topic the sentence meant — so none could match it to the ledger and close it; the operator had to point out that it keeps coming back. Now the gate stores up to 160 characters of the reply before the question, and `list` shows them under the question. The block reason also says that a decision made EARLIER (an order already in the ledger, a prior prompt) counts as `answered`. `test-question-gate.sh` +2: the context line is listed (fails without the fix); a question with no text before it prints no empty context line. Questions recorded before this change have no context and stay as they are.
