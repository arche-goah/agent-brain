The gate now reads the posted text (flag values and handed files) for backticked hex words of 7-40 characters with a letter and a digit, skips hex inside URLs, and per sha asks first a checkout of the target repo (`git branch -r --contains`, the repo from `-R`, the PR URL or the checkout's origin) and then, once, `gh api repos/<repo>/commits/<sha>`; only a 422 holds the post ("push first, then post"), anything unreadable passes with one stderr line. The check also runs when no instance id is set.
