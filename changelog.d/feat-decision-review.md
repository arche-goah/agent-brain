- **`scripts/decision-review.py`: every brain measures how often it asks its human, how often needlessly, and where it acted alone and was corrected — afterwards, from the transcripts.** (test: T1) Operator order 2026-10-16; designed by the macOS instance, co-signed by the Windows instance. No self-report per decision (a ritual that only logs what the AI itself takes for a decision — the class looked for, "decided without noticing", would fall through): the script reads the harness transcripts of the window plus question-gate's register and sorts five cases — a needed question, a needless one ("just do it"), a needless referral to a human, an action with external effect corrected for not asking, an action that stood. Two guards against the expensive false alarm: a correction counts as overreach only when it names the action, and a correction about a QUESTION never does; a compaction summary, a notification and a hook echo are no prompts, a prompt queued mid-turn is. Non-right cases are candidates with their transcript line; the brain-scan confirms or rejects them, and two confirmed of one action group become a proposal for the instance's operator-only list (or for loosening a rule) — never a change. `--numbers` prints counts only, no text, for sharing across instances. Language patterns are instance data (`templates/rules-instance/decision-review.json`, copied at bootstrap). Runs in the brain-scan's machine step (`brain-scan-prep.py`), never at session start; a per-file cache keeps reruns cheap. Measured on the macOS brain: 52 sessions, 771 MB in 4 s; 97 questions all needed, 2 referral candidates, 0 corrected actions out of 2062. Fixture `test-decision-review.sh` (18 cases, each guard planted; a mutant without the question guard fails it).
