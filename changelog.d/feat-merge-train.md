The operator (translated): "do the train branch, everything else is madness — new PRs keep coming". `scripts/merge-train.sh <pr>...` builds `train/<date>-<n>` from main and merges every PR's BRANCH head unchanged (never `refs/pull/N/head`, which lagged one push behind on #128 the same day), leaves out and names a PR that conflicts with the train so far, and prints the manifest (PR, branch, head sha) for the train PR's body. The train PR merges with a merge commit: every contained head is then reachable from main and GitHub marks those PRs merged. The ruleset's checks run once on the train; the OS checks by hand are asked once, for the train head.
