- **`scripts/autonomy-diagnose.py`: a read-only report on why a brain's AI asks before every step, run without Claude.** (test: T1) Observed 2026-10-16 on a collaborator's Windows brain on v1.3.41: a question per point, "commenting and pushing must always be user input", re-asking things tested before. Three causes look the same from outside — a core release without the question-reducing rules, a local rule read too widely, a missing permission pattern whose prompt the AI reports as "not allowed". The script separates them in well under a second, as one downloadable file that runs on any core version: core state and which question-reducing rules the loaded core carries; the always-loaded bytes against the harness limit and the memory index against its own; brake phrases (German and English) in local carriers with file:line and what they are about; how the settings answer push, PR comment/review/create/merge and the core's helpers; every wired hook; where a topic the AI should know lives and whether anything hands memory to it before it acts. Credentials are redacted. A messy brain does not stop it: every section runs on its own, and what the brain gets wrong (invalid or mistyped settings JSON, non-UTF-8 rule files, a BOM, an `@` import into nothing, an uninitialised `core/`, a broken hook entry, a folder without `CLAUDE.md`) is named in section 0. `--memory-dir` hands a follow-up agent the memory folder without the transcripts beside it; a template column shows whether a permission brake comes from `core/templates/settings.json`. **`scripts/autonomy-diagnose-run.sh`** runs the whole diagnosis unattended for a human who starts it in a plain terminal: it finds a Python by RUNNING it (a Windows Store `python3` stub resolves but does not run), runs the script, cuts the agent brief from a `--prompt` file at `<!-- agent-brief -->` and feeds it on stdin (a leading `---` is read as a CLI option), checks `claude --help` for every flag the read-only safe-mode run needs, and runs it; every step logs its exit code and error text, a step that cannot run is SKIPPED or FAILED with its reason, and the run folder (summary, environment, both reports, stderr per step) is what gets sent back. Exit 0 always. `english-only.py` skips the script and its fixture as detection data.
