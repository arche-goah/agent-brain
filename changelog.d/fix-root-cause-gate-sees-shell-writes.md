- **root-cause-gate reads absolute Windows paths in shell writes** (test: T1) (level: reader; higher: design — the harness telling a Stop hook which files a turn changed, not ours to build; debt: a path built from a shell variable or an escaped space stays unseen). Windows review 2026-11-12 (#468, inherited by #472): `shellWrites` needed a POSIX start, so `C:/...` and `C:\...` never matched, a quoted path with a space was cut at the space, and `/c/...` matched but node on Windows cannot stat it; a Windows session appending its register entry by absolute path kept hearing "no entry". The path reader now accepts a drive start and quoted paths with spaces, and runs every path through `nativePath` (docs/os-traps.md OS-19). `test-root-cause-gate.sh` +3 cases: the register written by an absolute quoted path with a space (red against the code before, measured on macOS), by its `cygpath -m` drive path and by its `/c/...` Git Bash path (both run only where cygpath exists, i.e. on Windows).
