# core/helpers — hook scripts (state of F2 cleanup 2026-07-29, path after core split 2026-08-04)

Everything here is wired up as a hook (`.claude/settings.json` hooks) — don't put
anything else here; ghost hooks were an audit finding (claude-flow import, 19 files
deleted, git history has them). Two exceptions: `statusline.cjs` (not a hook, table
below, installed at USER level via `scripts/install-statusline.sh`) and
`run-record.sh` (helper for scheduled jobs, called from launchers).

| Script | Event | Purpose |
|--------|-------|---------|
| session-bootup.sh | SessionStart | fast local sanity check (git/memory/settings/symlinks/brain-scan/tasks); one machine line from `scripts/machine-profile.sh` when the instance has `config/machines/` (identity from `config/machines/<key>.md`, tools measured live from `config/machines/probe-tools.txt`) |
| session-pull.sh | SessionStart (settings template) | opt-in (`config/session-pull.json`, template `templates/session-pull.json`): fast-forwards the brain and every repo `config/ecosystem.json` records, plus `extra` repos it does not carry (shared memory); never the core submodule or any submodule (they follow their pin); dirty/diverged = reported, untouched; no upstream = skipped; missing with a remote = cloned; per-repo stall limit + run budget, no `timeout`; stderr only, exit 0; `- Session pull: off` in the machine profile switches it off on that machine; fixture `scripts/test-session-pull.sh` |
| session-closing.sh | SessionEnd (+ `--pre-commit` from the session-close skill) | HANDOFF.md with real git data + line in docs/maintenance/session-log.md; the skill writes the line before the close commit, the hook only when no stamp says it is already there |
| memory-sync.cjs | SessionStart/SessionEnd/PreCompact | auto-memory <-> docs/memory-snapshot sync; 3-way against a per-machine base in `<live>/.sync-base.json` (the tracked manifest only says what the snapshot holds); never overwrites a side that moved since that base; export also prunes a snapshot copy whose memory this machine synced unchanged and then deleted (anything else is held) |
| file-guard.cjs | PreToolUse (Edit/Write) | protects sensitive files + branch gate: edits in a core checkout only on a feature branch (pin/main blocks) |
| mechanism-guard.cjs | PreToolUse (Bash, PowerShell) | blocks known ad-hoc shortcuts; rules are instance data (`.claude/rules/mechanism-rules.json`) |
| secret-guard.cjs | PreToolUse (Read/Edit/Write/Bash/PowerShell) | blocks secret channels into context/repo; patterns instance-extensible (`.claude/rules/secret-patterns.json`) |
| freshness-gate.cjs | PreToolUse (Workflow) | repeat-run rule carrier: fresh completed run of the same workflow → read artifacts instead of relaunching; thresholds instance data (`.claude/rules/freshness-gate.json`) |
| live-read-gate.cjs | PreToolUse (Bash, PowerShell, mcp__.*) | a live system is not touched before its mandatory reading was read COMPLETELY in this session — measured on the line windows the Read tool delivered, over the whole transcript; which tools/Bash commands are live and which files they require is instance data (`.claude/rules/live-read.json`, template `templates/rules-instance/live-read.json`); no file = inert; no bypass marker |
| live-watchdog.cjs | PostToolUse + PreToolUse (mcp__.*) | after every N write calls to a live system's tools its SUITE's check runs (argv, exit 0 green / 1 red / else could not measure = not red, retried); while red, further writes to that system are refused until a check passes (repair tools pass); state per project in `.claude-state/live-watchdog.json`; which tools write, N and the check are instance data (`.claude/rules/live-watchdog.json`, template `templates/rules-instance/live-watchdog.json`); no file = inert; a live-read domain without a check is named by `scripts/hook-coverage.py`; fixture `scripts/test-live-watchdog.sh` |
| skill-gate.cjs | PreToolUse (.*) | a tool is not called before the skill that declares it was loaded in this session (Skill tool, slash command, or Read of the SKILL.md); declared by the skill itself (frontmatter `metadata: load-before-tools` / `load-before-paths`, new skills need no registration) or by the instance for skills it does not own (`.claude/rules/skill-gate.json`, template `templates/rules-instance/skill-gate.json`); fail-open on its own plumbing; no bypass marker |
| conditional-order-gate.cjs | PreToolUse (Agent, Workflow, Bash, PowerShell) | an order that names a CONDITION is not acted on before the condition is checked — the mirror of promise-gate on the operator's side: when the operator's last message carries a sequencing word or a delegated decision ("then", "after your answer", "once X is merged", "clear it with X"), the first expensive or externally effective call of the turn (a Workflow, the third Agent, `claude -p`, a push, a PR write) waits for one line `CONDITION-MET: <condition> — <evidence>` or `CONDITION-NONE: <why not>` (in an earlier message, or as a comment in the call itself); built-ins English, the operator's language in `.claude/rules/condition-patterns.json` (template `templates/rules-instance/condition-patterns.json`); fail-open without a transcript; fixture `scripts/test-conditional-order-gate.sh` (measured 2026-10-16: "dann coherence scan" read as "now", nine agents before the awaited answer) |
| public-text-guard.cjs | PreToolUse (Bash, PowerShell) | text that goes to a PUBLIC repo — a `gh pr/issue/release` write, a `gh api` field or input file, a `git commit`/`git tag` message and its AUTHOR identity (`git var GIT_AUTHOR_IDENT`), and every file the command hands over (`--body-file`, `-F`, `@file`, `$(cat …)`) — only the PUBLISHED text is scanned (flag and field values, the `gh api` endpoint, the message, handed-over files; never paths, comments or the working directory; a command it cannot parse, such as a heredoc, is read whole) — names nobody from the brain's watch list (`.claude/rules/leak-names.json`, the list `scripts/staged-names.py` reads); visibility read from GitHub once a day per repo (cache `.claude-state/repo-visibility.json`), unknown = public; private repos pass; no watch list = inert; no bypass marker; fixture `scripts/test-public-text-guard.sh` |
| change-level.cjs | library of instance-key-gate + CLI (CI, session start) | every change declares its level: each `changelog.d/` fragment carries `(level: symptom\|reader\|writer\|design; higher: <level> — <why not> \| none; debt: … \| none)`, optional `settles-debt: <slug>`; `check` (CI, before `gh pr create`), `debts` (unsettled debts oldest first, `--brief` = one session-start line past 14 days); fixture `scripts/test-change-level.sh` |
| published-text.cjs | library of public-text-guard + instance-key-gate + mechanism-guard | the ONE reading of a shell command for outgoing-text gates: words and segments as the shell sees them (comments, quotes, `$(…)`, PowerShell backslashes), what gh/git PUBLISH (flag and field values, the gh api endpoint, the commit message, handed-over files), which commands a line RUNS (a quoted command is never one), and the line with published values blanked for regex rules; null on a heredoc or unbalanced quote = the caller reads the line whole; fixture `scripts/test-published-text.sh` |
| junk-cleaner.cjs | PostToolUse (Bash) | cleans up junk files |
| stop-verifier.cjs | Stop | verification reminder |
| question-gate.cjs | Stop (settings template) + CLI | a question to the operator (sentence ending in "?" that matches a proposal pattern; English built in, other languages in `.claude/rules/open-questions.json`) stays open in `.claude-state/open-questions.json` until settled by `question-gate.cjs resolve <id>=answered|dropped|deferred`; blocks once per turn when a question the operator has already seen is still open; `list` prints open and deferred ones at every session start; a close stamp passes the questions the close's session-log entry lists as `open end:`; fixture `scripts/test-question-gate.sh` |
| watch-gate.cjs | Stop (settings template) | an own act that expects a reaction — a shared-memory entry from this instance to another party that is not `status: info`/`done`/..., or `gh pr create` — must not end the turn without a LIVE watcher (pid in the lock of `shared-memory-watch.sh` / collab-watch answers `kill -0`; an expired Monitor counts as not armed); blocks once per turn; a close stamp passes the items the close's session-log entry lists as `open end:`; fixture `scripts/test-watch-gate.sh` |
| close-stamp.cjs | library of question-gate + watch-gate | the session-close exception: valid only when the running turn called `session-closing.sh --pre-commit`, the stamp is not older than the turn and names this session (or none); returns the `open end:` lines of the entry the stamp points at; fixtures `scripts/test-watch-gate.sh`, `scripts/test-question-gate.sh` |
| recall-gate.cjs | Stop (via stop-dispatcher, `stop-checks.json`) | knowledge without a carrier, two triggers: live-research tool calls above threshold, OR verification CLAIMS in the agent's own text (a verification verb AND a discovery object in the same block, `verifyThreshold` of them) — either one with nothing persisted since → one question; `--record` for precision measurement; tool patterns, word lists and persistence paths are instance data (`.claude/rules/recall-tools.json`, English defaults, config replaces rather than extends); read side = `scripts/transcript-recall.py` |
| absence-gate.cjs | Stop (via stop-dispatcher, `stop-checks.json`) | absence claims ("documented nowhere", "never measured") need a search over every registered source root in the same turn; Grep/Glob/Read/Bash-search paths are checked against `.claude/rules/absence-sources.json` (`roots`, plus `claim_patterns`/`scope_markers` that extend the English built-ins); a visible `⚙ scope:` line lets a narrower search pass; no roots file = inert; `--record` for precision measurement (template: `templates/rules-instance/absence-sources.json`) |
| notify.cjs | PostToolUse (Agent/Task) + Notification | sound on agent end / permission question |
| statusline.cjs | statusLine (NOT a hook; user-level `~/.claude/settings.json`) | footer: model, 5h/7d rate-limit remaining with reset countdown, context % — install: `scripts/install-statusline.sh` |

Active session close: skill `session-close` (SessionEnd is only a best-effort fallback).
